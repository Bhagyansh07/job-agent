# Remote boards (key: remote_boards | cap 12/day total)

Sources: weworkremotely.com (Programming), remoteok.com, himalayas.app, remote.co, wellfound remote, hnhiring.com / HN "Who is hiring" monthly thread, lennysjobs, Ramp/a16z/Founders-You-Should-Know style startup lists.
- Only roles open to India (or "worldwide"/"APAC") and entry/junior level. Check timezone overlap and salary >= 8 LPA equivalent (e.g. USD 1,000+/month).
- Toptal/Crossover: skip (long tests, not entry level). Ignore listings older than 14 days.
- Apply via the company's own page/email form; never send emails/cold mails unless the listing explicitly requires an email apply - in that case ask on Telegram first.

## General
UI changes often: take a fresh page snapshot, don't rely on fixed selectors. Follow skills/apply_flow.md. Log every decision with tracker.py (portal key shown below).
