# Instahyre (key: instahyre | cap 10/day | strict hours)

Instahyre is mostly opportunity-based: companies send "opportunities"; also has job search.
- Open "Opportunities"/"Jobs for you": for each card read JD, score, then "Interested"/"Apply" only on >= 80 (60-79 ask).
- Keep profile fields complete (skills, preferred locations: Delhi NCR/Gurgaon/Jaipur/Remote, expected CTC from answers.yaml).
- Never reply to employer messages; alert on Telegram.
